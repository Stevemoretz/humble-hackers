# Humble Hackers Landing Page

This is a responsive landing page inspired by [The Humble Hackers's Offical Website](https://thehumblehackers.com/), built from scratch using **Next.js** and **Tailwind CSS**. It is not a 1:1 clone but reimagines the design with a modern, static-generated approach, deployed to GitHub Pages.

## Live Demo
Check out the live site: [https://stevemoretz.github.io/humble-hackers/](https://stevemoretz.github.io/humble-hackers/)

## Features
- **Responsive Design**: Adapts seamlessly to mobile, tablet, and desktop screens using Tailwind CSS.
- **Next.js**: Leverages Next.js for static site generation and optimized image handling.
- **Tailwind CSS**: Utilizes utility-first styling for rapid development and consistent design.
- **Static Export**: Deployed as a static site on GitHub Pages for fast, reliable hosting.
- **Clean Structure**: Modular components and organized codebase for maintainability.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/stevemoretz/humble-hackers.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run in development mode:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the site.
4. Build for production:
   ```bash
   npm run build
   ```

## Notes
- The design is inspired by The Humble Hackers but rewritten with a focus on simplicity and performance.
- Images are unoptimized for static export, with `basePath` handling for GitHub Pages.
